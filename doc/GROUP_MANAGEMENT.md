# QQ 群管理与群资料

配置有效的本机 OneBot 后，可在普通聊天中用自然语言查看群信息、成员和直接入群申请，提出禁言、解禁、移出成员、修改群名及同意 / 拒绝申请。

## 审批

输入框上方显示具体操作、群和成员、时长或新名称，以及 **允许 / 拒绝**。

| 当前对话设置 | 行为 |
| --- | --- |
| 每次询问，默认 | 等待用户确认具体操作 |
| 默认允许 | 对之后的新任务执行通过权限检查的操作，并记录结果 |
| 默认拒绝 | 记录提案，不执行 |

切换设置不会批准之前的待审批项。模型不能修改审批规则、批准自己或任意调用 OneBot。工作区、关注卡和回复助手没有群管理写工具；回复发送使用独立审批。

## 权限与结果

提出和执行操作前分别核对登录账号、群、目标及当前权限。普通成员不能管理，也不能禁言或移出本人、群主或权限不低于自己的成员。同名必须核对稳定账号。

申请必须来自接口真实返回并重新核对；目前不处理邀请当前账号加入其他群。操作幂等领取、限制数量并保留审计。过期、拒绝、失败、取消和结果未知分别记录；回执丢失时不自动重试，应先在 QQ 核对。

## 公告、精华和群文件

有效连接时提供按需资料工具；无配置或探测失败时不向模型提供实时群工具，本地已导入资料仍可使用。每轮访问受原有范围和预算限制。

公告、精华保留独立来源，加精时间不冒充消息发送时间。群目录先列元数据，需要正文才下载指定文件、解析和读取。Token 不转发给文件服务器。

普通聊天、关注卡和工作区可按需使用获准的群资料。缓存与本地变化流不能保证服务器上的全部更新已经自动进入本地；见 [FEATURES.md](FEATURES.md)。

配置步骤见 [SNOWLUMA_SETUP.md](SNOWLUMA_SETUP.md)。公开回归使用模拟服务，不向真实群发送测试消息或执行管理操作。
