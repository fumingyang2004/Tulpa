# Tulpa 0.5.3

本次更新集中在 MCP 持续群聊：新增龙娘人格、纳入维护者最新修改的小鲸鱼，完善表情收藏与候选，并支持原生引用和 @。完整版的 MCP 与轻量版使用相同实现，内置 Harness 不会因此变成自动群聊机器人。

## 下载

| 文件 | 用途 |
| --- | --- |
| `Tulpa-0.5.3-win-x64.zip` | 完整版：内置 Harness、MCP、本地 OCR / 语音 / Office 解析、固定 WebView2 |
| `Tulpa-MCP-0.5.3-win-x64.zip` | MCP 轻量版：导入、实时读取、聊天浏览、OneBot 和 MCP；语音模型按需安装，使用系统 WebView2 |
| `SHA256SUMS.txt` | 两个安装包和 FFmpeg 源码归档的 SHA256 |
| `FFmpeg-b08d7969c5-source.tar.gz` | 随包 FFmpeg 对应源码；普通使用无需下载 |

Windows 10/11 x64。完整解压后打开 `Tulpa/Tulpa.exe`。两个包均从同一源码提交构建，不包含作者的聊天、模型配置、OneBot / MCP Token 或运行日志。SnowLuma、NapCat 与 QQ / 微信客户端不随包分发。

## 本次变化

- **两张随包角色卡**：新增 GPT 白龙娘 `dragon_girl`；小鲸鱼 `little_whale` 更新为维护者当前版本。卡片全文直接随包，保留小鲸鱼的上游来源和修改记录。角色名称不代表实际模型，外部 Agent 使用的模型不会改变。
- **表情从看懂到复用**：当前群图先实际看图，可直接发送；在已有收藏授权下，可一次收藏并填写内容理解、情绪、用途、标签与限制。QQ 收藏、本地原件、语义笔记分别返回结果，部分失败不抹掉已保存成果。
- **跨会话的熟悉候选**：同一 MCP 授权与 QQ 账号下，理解笔记和原件可在重启后复用。每轮默认最多四个可用候选，结合关键词、常用与轮换，抑制刚使用的图片；不每轮下载整库，不强制发图频率。原件缺失、哈希改变、撤权或范围不符时不能直接发送。
- **用量与诊断**：确认发送成功后才累计用量；失败不记成功，UNKNOWN 不自动重发。候选为空、搜索无命中、读图失败、未观察到发送调用等状态分别记录，不推测模型内部想法。
- **真实引用与 @**：持续群聊文本发送可以独立选择回应目标、原生引用和成员 @；默认普通文本，不继承上一条的标记。目标必须已读取、仍在允许范围，并通过 OneBot 校验。
- **SnowLuma 配置导入**：选择已有 SnowLuma 文件夹、账号和 HTTP / 正向 WS 节点，检测同一账号后保存到 Tulpa。两路 Token 分别处理，保留手动入口，不修改 SnowLuma 配置或扩大 MCP 授权。
- **QQ 读取维护**：加入账号路径诊断、既有自定义来源目录的读取支持和被动密钥扫描回归。用于旧版 0.5.1 的临时修复脚本保留在源码，不是新版的必要升级步骤。客户端版本、登录状态和权限仍会影响读取，不能保证所有电脑都能取得密钥。

表情细节与容量策略见 [MCP_STICKERS.md](../MCP_STICKERS.md)，配置教程见 [SNOWLUMA_SETUP.md](../SNOWLUMA_SETUP.md)。NapCat 只读探测与评估保留在源码，**不是本次默认历史后端切换**；限制见 [评估记录](../NAPCAT_QQ_EVALUATION.md)。

## 启用人格与表情

配置好 OneBot HTTP / 正向 WebSocket，并在 MCP 连接中选择需要的持续群聊、发送、看图、表情发送和收藏权限。在外部 Agent 的专用对话中说：

> 先列出当前人格，再用 `dragon_girl` 在我的测试群持续聊天，直到我停止。在已有授权内按语境看图、选择表情，也可以只发文字或沉默。

想用小鲸鱼时改为 `little_whale`。新增卡片仍可放入当前运行目录的 `chatlocal/prompts/mcp_chat/`，热发现无需重启。旧会话保留原人格快照，更新角色后须停止并重新开启会话。详见 [持续群聊教程](../MCP_CHAT.md)。

## 保留数据升级

按 [升级教程](../UPGRADE.md) 使用新版 `scripts/upgrade_installation.py` 检查、备份并更新原安装目录，保留聊天、附件、MCP 授权、实时进度、表情笔记和本地图库，无需重新导入。完整包与轻量包分别升级，不混装。

如果修改过随包 `little_whale.md`，或旧目录已经有自己写的同名 `dragon_girl.md`，先另存为不同文件名，再升级。升级工具会备份替换文件，但同名随包卡片会采用新版内容。不要用旧授权数据库覆盖新操作回执。升级后打开原 EXE，在外部客户端重连 MCP、刷新工具；无需重建原连接或自动扩权。

## 验证边界

自动验收使用隔离数据库、合成图片及本机模拟 OneBot HTTP / WebSocket，覆盖人格全文与快照、引用 / @、表情持久化、权限和账号隔离、幂等、UNKNOWN、断线与候选成本。安装包另检查运行时、启动、文件清单、隐私边界和 SHA256；详细记录见 [验证说明](../VALIDATION.md)。

这些检查不代表真实 QQ 全版本兼容，也不能证明模型自然发图的频率提高。此次发布不发送真实 QQ 测试消息、不执行真实收藏、不调用付费模型。真实群聊观感由用户在自己的授权范围内体验；模型持续运行仍取决于外部宿主。
