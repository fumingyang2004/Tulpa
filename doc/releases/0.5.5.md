# Tulpa 0.5.5

本版汇总 0.5.3 之后的 MCP 持续群聊、语言学习与 SnowLuma 接入改进。完整版和 MCP 轻量版使用相同的 MCP 实现；内置 Harness 不会因此自动水群。不需要额外模型服务或新的 API Key。

## 下载与启动

- `Tulpa-0.5.5-win-x64.zip`：完整版，含内置 Harness、本地 OCR / 语音 / Office 解析和固定 WebView2。
- `Tulpa-MCP-0.5.5-win-x64.zip`：MCP 轻量版，使用系统 WebView2，语音模型按需安装。
- `SHA256SUMS.txt`：两个 ZIP 及 FFmpeg 源码归档的 SHA256。
- `FFmpeg-b08d7969c5-source.tar.gz`：随包 FFmpeg 对应源码，普通使用无需下载。

Windows 10 / 11 x64，.NET Framework 4.8。完整解压后打开 `Tulpa/Tulpa.exe`。包中不含作者聊天、账号、模型配置、MCP / OneBot Token 或私人测试记录，也不附带 QQ、微信、SnowLuma 或 NapCat。

## 本次变化

- **SnowLuma 单入口配置**：自行下载并解压官方 Windows x64 完整包，在 Tulpa 输入路径、主动勾选授权，点击一次“载入并配置”。移除重复的载入和导入表单；设置与 MCP 入口共用状态，多账号或节点存在歧义时在原位置选择。已有有效连接可核对后导入；全新 v1.14.22 目录具备自动初始化和指定 QQ 进程接入流程。Tulpa 不自动下载或分发 SnowLuma，不接管其他实例、不自动扩大 MCP 授权。[配置及恢复](../SNOWLUMA_MANAGED.md)
- **同一 Agent 先决定，再表达**：Planner 记录已读批次、目标与表达方式，Replyer 组织内容；程序检查连续输入、相关新消息及发送队列。支持一至三条语义气泡、被插话后停止尾部、沉默和仅表情回应。过期决定需要补读，不盲目重发未知结果。[聊天节奏](../MCP_CHAT_TURNS.md)
- **独立小鲸鱼2号**：随包 `little_whale_v2` 纳入维护者当前修改，继续保留小鲸鱼与龙娘。人物卡热发现，已开始的会话使用创建时的快照；切换需要停止并重新开始。
- **消息表情回应**：可对当前会话已读且有效的群消息添加或撤销目录内回应，也能收到他人的回应并关联到原消息；纯 reaction 可以结束本轮。受现有授权、目标校验、冷却及幂等机制约束。[回应目录与权限](../MCP_REACTIONS.md)
- **边聊边学群友表达**：持续聊天默认观察当前已授权账号与群的新消息，潜水也能推进；已有明确暂停选择会保留。服务端按消息和时钟准备学习阶段，Agent 每次只推进一阶段，聊天优先。学习素材排除机器人输出与工具结果，表达必须有真实群友原话支持；自检不等于独立审核。[学习说明](../MCP_LANGUAGE_LEARNING.md)
- **学习接续与按轮采用**：学习库按机器人账号和群隔离，同范围重开保留积累、人工修订和停用状态。合格表达不足十条不注入；达到门槛后，文字回复前明确选择零至五条参考，或本轮不用，并记录工具返回中的实际准备情况。黑话按有效批次积累、分阶段检查，补充有界缓存匹配，不把候选写成已掌握。
- **界面与可靠性**：持续群聊与学习收进独立管理面板，只能从外部 Agent 对话发起；界面区分潜水、等待 Agent、积累、学习和预算暂停。完善工具参数诊断、有界恢复及前端刷新；保留文字、图片、表情包、原生 @、引用和历史查询。

## 升级与使用

按 [保留数据升级教程](../UPGRADE.md) 用新包中的升级工具更新原安装目录。完整版和轻量版分别升级，不混装；停止持续群聊并从托盘彻底退出后再更新。自改的同名随包人格先另存，升级备份留在本机。聊天、附件、授权、表情图库、学习库和实时读取进度无需重新导入。

升级后启动原目录 EXE，在外部 Agent 重连 MCP、刷新工具，并开一个专用对话，例如：

> 列出可用人格和允许的群，核对我的测试群后，用小鲸鱼2号持续聊天，直到我停止。接得上话再说，也可以潜水。

已有连接不会自动增加发送、收藏或回应权限。需要新增能力时在界面明确授权。群聊和学习仍依赖外部 Agent 持续运行；Tulpa 不会自行启动模型，不能强制打断宿主正在生成的内容。

## 验证范围

发布门槛包括开发环境检查、两版随包运行时回归、实际 full / lite 页面浏览器夹具、全新目录启动，以及两个 ZIP 的文件清单、隐私检查、CRC 与 SHA256。具体提交、CI 与构建结果记录在 [GitHub Release](https://github.com/fumingyang2004/Tulpa/releases/tag/v0.5.5)，包内 `build-manifest.json` 记录来源提交及每个程序文件的哈希。

本次打包验收不发送真实 QQ 消息、不真实收藏、不调用付费模型。此前授权的有限真实群聊、表情回应和学习样本分别记录于 [回应验收](../MCP_REACTION_CATALOG_VALIDATION.md)、[聊天节奏](../MCP_CHAT_TURNS.md)和[学习说明](../MCP_LANGUAGE_LEARNING.md)，不能替代全版本兼容或长期自然程度保证。

SnowLuma 新目录初始化经过隔离 API、真实本机 HTTP / WS 与操作系统机制测试；已有 v1.14.20 连接经过本机只读核对。**全新 v1.14.22 的真实 QQ 首次初始化、多 QQ、扫码与系统重启矩阵尚未全部实测**，不将模拟通过写成真机全自动验收。[详细边界](../SNOWLUMA_MANAGED_VALIDATION.md)
