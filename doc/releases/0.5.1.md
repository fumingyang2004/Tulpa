# Tulpa 0.5.1

同时发布完整版和 MCP 轻量版。**两版的 MCP 功能一致**；内置 Harness 保持原来的调查、回复、记忆和工作区流程，持续群聊仅提供给外部 MCP Agent。

## 下载

| 文件 | 用途 |
| --- | --- |
| `Tulpa-0.5.1-win-x64.zip` | 完整版：内置 Harness + 全部 MCP 功能，自带固定 WebView2、OCR、语音模型和 Office 解析 |
| `Tulpa-MCP-0.5.1-win-x64.zip` | 轻量版：本地读取、浏览、OneBot、MCP；使用系统 WebView2，语音模型按需安装 |
| `SHA256SUMS.txt` | 两个安装包和 FFmpeg 源码归档的校验值 |
| `FFmpeg-b08d7969c5-source.tar.gz` | 随包 FFmpeg 对应源码，普通用户无需下载 |

Windows 10/11 x64，完整解压后运行 `Tulpa.exe`。QQ、微信及 SnowLuma 等 OneBot 服务仍由用户单独运行，不在压缩包内。包内没有用户聊天、账号配置、模型密钥或 MCP 凭据。

## 本次变化

- **持续群聊**：输入人格与目标群，外部 Agent 可以持续等待消息和按需发言，不必设置总时长；用户可随时停止。等待使用独立通道，不占用普通调查工具的并发槽。
- **OneBot 直接接收**：群聊消息从 SnowLuma 正向 WebSocket 获取，不再依赖历史聊天导入或 QQ 数据库实时读取。账号、群和日期范围仍受连接授权限制；有重连、事件去重、游标确认与接收间断提示。
- **聊天中的图片和表情包**：按授权读取图片像素、查看 QQ 收藏、记下表情用途、发送原动画，以及收藏到 QQ。看图、发送、收藏分别授权，默认关闭；图片处理与历史工具、消息等待分离。
- **可保留数据的升级工具**：新版 `scripts/upgrade_installation.py` 先检查，再备份更新原目录的程序。聊天、附件、记忆、MCP 端口和授权、账号选择、实时读取设置及进度留在原路径，无需重新导入。
- **微信媒体容错**：损坏图片的解码错误不会令整批实时读取一直显示受限；保留媒体恢复路径。

## 从 0.5.0 升级

**不要开一个空的新目录再重新导入。** 将新版解压到临时目录，彻底退出旧版，按 [升级教程](../UPGRADE.md) 使用新版工具更新原来使用的安装目录。教程包含可直接交给 Codex / DeepSeek Harness 的执行指令、数据校验、监听检查与回退说明。

已有 MCP URL / Token 可以继续使用，客户端重新连接即可。新增持续群聊和表情权限不会自动授予旧连接；需要时在界面创建新授权。SnowLuma 原来只有 HTTP 节点的用户需另外启用正向 WebSocket。普通 QQ / 微信数据库实时读取仍按原设置工作，不受这个节点影响。

## 使用边界

外部 Harness 必须持续运行并执行等待循环，Tulpa 不会自行调用模型维持聊天。模型需支持 MCP 图像才能看图。动画最多采样三帧，发送保留原件；无法保证理解每一帧。停止或撤销可阻止尚未派发的操作，已经提交 QQ 的操作不能靠停止撤回；未知发送结果不自动重试。离线或断线期间消息不承诺完整补齐。

验证方法与本机实测范围见 [VALIDATION.md](../VALIDATION.md)。
