# Tulpa 0.5.0

同一版本提供完整版与 MCP 轻量版，均为 Windows 10 / 11 x64 便携程序，完整解压后运行 `Tulpa/Tulpa.exe`。

## 选择下载

| 附件 | 用途 |
| --- | --- |
| `Tulpa-0.5.0-win-x64.zip` | 完整版，保留内置 Harness、聊天查询、回复助手、记忆、关注卡、工作区；同时提供 MCP。自带固定 WebView2、本地 OCR、语音模型和 Office 解析依赖 |
| `Tulpa-MCP-0.5.0-win-x64.zip` | 轻量版，提供导入、实时读取、聊天浏览、OneBot 和 MCP；任务交给 Codex、DeepSeek Harness 等外部 Agent。使用系统 WebView2，语音模型需要时在首页安装 |
| `SHA256SUMS.txt` | 两个 ZIP 和 FFmpeg 源码归档的 SHA256 |
| `FFmpeg-b08d7969c5-source.tar.gz` | 随包 FFmpeg 的对应源码，普通用户无需下载 |

GitHub 自动提供的 Source code 是源码，不是可运行桌面包。两个版本请分别解压到独立目录，不要混合覆盖程序文件。QQ / 微信客户端和 SnowLuma 等 OneBot 服务由用户自行安装，发布包不附带账号、模型 API Key 或聊天资料。

## 相对 0.3.1 的主要变化

- 桌面内配置通用 Streamable HTTP MCP：选择平台、会话、日期和处理权限，创建与撤销连接，检测服务，复制客户端配置。创建连接可以同时启动服务，避免“保存配置后才可操作”的流程歧义。
- 只使用外部 Agent 时无需在 Tulpa 配模型。OneBot 配置可独立保存；完整版本的内置模型继续由用户填写 URL、API Key 和模型名。
- 增加 MCP 轻量包：移除内置 Harness、Gradio、Office 解析框架、本地 OCR、固定浏览器和随包语音模型。可选语音模型显示安装进度，支持取消、固定大小和 SHA256 校验，安装后离线转写。
- MCP 支持授权范围内的聊天、身份、上下文、统计、图片、语音与文件，以及 OneBot 公告、精华、成员和群文件目录。
- 新增 `download_file`：OneBot 下载原文件后返回本机路径、文件名、大小和 SHA256，外部 Agent 用自己的文件工具阅读。不要求先经过 Office 解析；保留轻便的 PDF / 文本提取。每个文件最多 32 MiB，与文字提取合计每小时最多 12 次。
- 在 OneBot 读取权限下方增加“允许直接发送 QQ 消息”和“允许直接执行 QQ 群管理”。默认关闭；勾选为该连接的持续授权，无需回 Tulpa 逐项批准。目标范围、账号与实时权限仍会检查，支持撤销、操作记录、幂等及未知结果不自动重试。
- 托盘继续服务和可选开机启动；关闭网页不等于停止独立外部 Harness。
- 补充 DeepSeek Harness 配置、换 Token 后重连及原文件交接教程。

## 验证与边界

本机 Codex CLI 与官方 DeepSeek Harness 已实际读取资料，并在授权测试群完成发言、临时改名与恢复；没有踢人或改变成员原有禁言。OneBot 原文件下载、本地语音模型安装和转写已经实测。两个桌面包还会使用随包 Python 运行读取器、范围隔离、OneBot 和写操作隔离回归。

外部 Harness 的本地 PDF 命令处理在本轮独立 CLI 测试中受到执行策略 / Windows 沙箱限制，因此原文件下载成功不等于所有外部文件格式已验收。没有第二台电脑的本次精简包验收；没有真实踢人或入群申请处置验收。详情见 [验证说明](../VALIDATION.md)。

## 升级与使用

升级同一版本类型前彻底退出并备份，保留自己的 `data/`、`imports/` 和 `.env`。切换完整 / 轻量版时先解压到新目录，再按 [数据与升级](../MCP_LITE.md#数据与升级) 迁移。两个实例不要共用同一数据目录或 MCP 端口。

连接新数据目录或更换凭据后，在外部 Harness 更新 MCP URL / Token 并重启客户端。MCP Token 与 OneBot Token 不是同一个。轻量版缺少 WebView2 时按启动提示安装微软官方 Evergreen Runtime。
