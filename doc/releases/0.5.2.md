# Tulpa 0.5.2

本次集中优化 **MCP 持续群聊的人格与接话**。完整版和 MCP 轻量版包含相同的新功能；内置 Harness 的普通聊天、回复助手、记忆、关注卡和工作区继续使用原有流程。

## 本次变化

- **分层群聊提示**：工具协议、群聊行为、人格与每轮接话提示分开组织。模型结合当前话题、明确的 @ / 引用、可能未说完的半句、发言密度和参与程度决定是否接话。空闲时继续等待，不用“我会在线”代替实际执行。
- **小鲸鱼预设**：基于 qq-bridge 的角色卡，纳入 Tulpa 维护者对口语、调侃、复读和回复示例的修改，保留来源和 MIT 许可。这是角色设定，不会改变外部 Agent 实际使用的模型。
- **Markdown 人格热发现**：将 UTF-8 `.md` 放入当前安装目录的 `chatlocal/prompts/mcp_chat/`，`list_chat_personas` 即可列出最新数量、名称和 id。支持中文文件名，无需重启或修改注册表。新增、修改、删除只影响新建会话；已经开启的群聊保留人格全文快照。
- **更贴近语境的表情提示**：已看过的表情可记录含义、适用场景并按授权收藏；后续接话提示会带入相关笔记，模型再看实际图片、选择发送。提示组装本身不会自动下载图片或调用模型。
- **隔离保持不变**：新提示仅用于 MCP 水群。实时消息继续来自 OneBot WebSocket，不依赖历史数据库读取；等待、媒体处理和其他 MCP 查询使用独立通道，发送、看图与收藏仍分别受授权控制。

## 开始使用

先按 [OneBot 教程](../SNOWLUMA_SETUP.md) 和 [MCP 教程](../MCP.md#持续群聊snowluma-实时事件) 配置 HTTP 与正向 WebSocket，并在 MCP 连接中授予持续群聊、发送及所需的表情权限。

在外部 Agent 的专用对话中说：

> 先列出当前可用的人格，再用小鲸鱼预设在“测试群”持续聊天，直到我停止。

自定义卡片、提示传递、表情链路和停止方式见 [水群人格与接话](../MCP_CHAT.md)。QQ、SnowLuma、Tulpa 和外部 Agent 都需要保持运行；Tulpa 不会自行启动模型续聊。

## 从旧版升级

使用相同类型的包，按 [升级教程](../UPGRADE.md) 更新原安装目录。聊天、附件、MCP 授权、账号选择和实时读取进度保留，无需重新导入。升级后在 Codex / DeepSeek Harness 等客户端重新连接，刷新工具列表。

自己新增且不与随包文件重名的人格会保留。**如果修改过随包的 `little_whale.md`，升级前先另存为 `我的小鲸鱼.md`**，防止随包预设更新覆盖你的改动。升级工具也会备份被替换的旧文件。已有会话继续使用创建时的人格，要体验新版角色卡请停止旧会话后重新开启。

## 验证与边界

本机验证了人格热发现与快照、真实 MCP HTTP 协议连接、隔离 OneBot HTTP / WebSocket 的消息接收、并发等待、断线重连、停止撤销、发送幂等，以及图片、动画、收藏、笔记和权限隔离。当前小鲸鱼在本机模型的 13 个合成场景中，单步工具选择均符合预期，包括接话、沉默、半句等待、先看图和自定义人格。

合成测试未向真实 QQ 发送消息，也不代表所有模型都有同样的幽默感或能永久在线。外部宿主仍决定模型预算和任务存续；模型结束执行后需用户接续。升级及两个包的运行时检查由构建流程执行，持续集成另检查原有功能回归。
