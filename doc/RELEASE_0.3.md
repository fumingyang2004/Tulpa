# Tulpa 0.3.0

首个公开源码与 Windows x64 便携版本。

## 包含的能力

- QQ / 微信本地导入、分批读取与进度、实时摄取和实时聊天浏览。
- Agent 查询、上下文阅读、人物解析、受限统计与原文证据。
- 图片 OCR / 原生识图、本地语音转写、按需文件解析。
- 可编辑的回复草稿、历史互动案例、可关闭的会话行为记忆。
- 关注卡、持续工作区、Markdown / CSV 成果、审批、版本与回退。
- 可选 OneBot：QQ 回复发送、群管理审批、公告 / 精华 / 群文件读取。
- 默认系统字体、暖色浅色界面、新黑白 Logo，以及简化的“记忆”入口。

## 安装与升级

下载 `Tulpa-0.3.0-win-x64.zip`，完整解压后运行 `Tulpa/Tulpa.exe`。Windows 10 / 11 x64，.NET Framework 4.8；不需要另外安装 Python 或 WebView2。

首次在模型设置填写自己的 API 配置。OneBot 是可选扩展，服务需独立安装，步骤见 [配置教程](SNOWLUMA_SETUP.md)。本包不包含 SnowLuma 服务。

升级前退出旧程序并备份。合并程序文件时保留个人 `.env`、`data/`、`imports/`；不要让两个版本同时操作同一数据目录。标准包不包含任何人的账号、聊天或 API Key。

## 当前边界

- 客户端读取依赖本机版本、权限、密钥与缓存，不保证完整服务器历史。
- 微信只支持回复草稿，不支持实际发送；QQ 发送需审核。
- 工作区自动维护只提出修改建议，不直接应用正式成果。
- 群管理写操作仅在普通聊天中提供，不在关注卡或工作区后台执行。
- 模型结果、OCR 和转写仍可能出错，引用有效不保证解释正确。
- Windows EXE 未做商业签名；源码和构建方法已公开。

下载程序请选择 `Tulpa-0.3.0-win-x64.zip`。`FFmpeg-…-source.tar.gz` 是随包图像解码组件的源码附件，不是另一个 Tulpa 安装包；完整性摘要见 `SHA256SUMS.txt`。
