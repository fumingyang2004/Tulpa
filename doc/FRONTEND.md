# 完整图形界面

完整版共用 `web/desktop/` 下的原生 JavaScript 模块与 Hash 路由，后端通过 `/ui/` 提供资源。运行时不需要 Node、npm、前端构建服务或外部 CDN。轻量 MCP 版继续使用 `web/` 下的经典组件及共享表单。

`app.js` 提供组件、请求、主题、路由和任务状态；`desktop.js` 注册页面及设置。功能按页面划分：

| 路由 | 功能 |
| --- | --- |
| `#/home` | 本机概览、最近聊天、运行及同步状态 |
| `#/chat` | 通过既有 Gradio 队列进行对话、流式回答、引用及审批 |
| `#/chats` | 聊天目录、历史分页、增量更新、媒体及回复抽屉 |
| `#/watches` | 关注卡、检查、追问、频率与消息阈值 |
| `#/files` | 文件目录、取得、解析、片段阅读及证据保存 |
| `#/collections` | 证据集合、QQ 公告及精华资料 |
| `#/memory` | 社交记忆、人工修正及成长记录 |
| `#/workspaces` | 工作区、任务、成果、版本及审计 |
| `#/data` | 账号读取、历史来源、同步、导入、媒体、语音及范围删除 |
| `#/agents` | MCP 服务、动态权限、授权编辑、私聊选择及群聊学习 |
| `#/settings` | 主题、模型、OneBot、SL 托管及桌面设置 |

macOS 使用 SL Docker，通过受限原生桥打开系统浏览器扫码；Windows 使用本机 SnowLuma 文件夹、协议授权及 QQ 进程选择；Linux 可选本机或 Docker。已有安装遵从后端绑定，变更目录或模式使检测回执失效，开始托管仍要求主动勾选授权。本机模式使用 QQ 原生登录窗口。

侧栏可收起、展开并适配小屏；主题支持浅色、深色与跟随系统。Mac 外观同步原生标题栏并保存在项目数据目录，普通浏览器使用本地存储。VNC 操作结果与托管状态分别显示，失败后保留可复制地址及默认隐藏的密码。

每次导航持有独立的页面容器。同页异步挂载按生命周期排队，迟到结果只能写入已分离容器，清理函数执行一次。请求助手为管理写操作统一提供 JSON 体及相应请求头。来源切换只在用户保存后生效，保留已有目录及密钥引用。

资源继续使用白名单路由。页面不放宽 CSP，不依赖内联脚本或 `eval`；macOS 原生桥只接受本机主页面的固定动作，不能传入任意命令或目标地址。登录面板隐藏或销毁时清空凭据。

检查方法与模拟范围见 [前端检查](../tests/frontend/README.md)，Mac 实机结果见 [验收记录](../macos/ACCEPTANCE.md)。前端及其 SL 平台适配由 Claude Code CLI（DeepSeek deepseek-flash[1M]）实现；后端、原生桥、接口整合、独立检查和发布整理由 Codex（GPT-6）完成。
