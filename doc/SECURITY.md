# 安全与隐私报告

请不要在公开 Issue、PR 或附件中提交 API Key、OneBot Token、解密密钥、原始聊天、个人账号、整个数据目录或未经检查的日志。

优先使用仓库 Security 页面中的 **Report a vulnerability** 私下报告漏洞，提供影响范围和不含个人数据的复现步骤。一般使用问题可提交公开 Issue，附上脱敏版本、错误码和最小示例。

Tulpa 的内部服务只面向 localhost。不要通过公网转发应用端口或 OneBot 接口。运行过的程序目录包含个人数据和配置，不能作为公开 Release 上传。

MIT 许可不改变模型供应商、QQ / 微信及独立接入服务各自的数据与使用条款。
